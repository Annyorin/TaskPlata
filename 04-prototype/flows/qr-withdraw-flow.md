# План флоу: снятие по QR

Что проектировать до пикселей. Узлы и переходы — из [`IA.md`](IA.md).
Сценарии — [`scenarios.md`](scenarios.md). Карта на доске — [`figjam.md`](figjam.md).

## 1. Обзор

| | |
|---|---|
| **Фича** | Снять наличные в банкомате Plata без карты: заявка в приложении → поиск банкомата → живой QR у банкомата |
| **Кто** | Держатель счёта / кредита Plata, iOS. Карты нет с собой, ещё едет или заморожена |
| **Цель** | Получить нужную сумму с первой попытки, без скрытой комиссии, ≤ 30 с у банкомата |
| **Старт** | Главная (карточка «Наличные»), экран карты («Снять без карты»), пуш / Live Activity по живой заявке |
| **Успех** | Чек DONE: купюры выданы, списано ровно обещанное, Live Activity гаснет |
| **Провалы** | Отмена до выдачи (деньги не списывались); сбой выдачи → FAIL + автовозврат; «это не я» → ESC-ALERT |

Три фазы одной работы, не три продукта:

1. **В приложении** — сумма, счёт, цена, заявка на 24 часа.
2. **Поиск банкомата** — какой открыт, хватит купюр, успею до закрытия.
3. **У банкомата** — «Снятие по QR» на экране банкомата → живой QR на телефоне → скан → биометрия → купюры.

## 3. Матрица состояний

### W-CASH

| Состояние | Триггер | На экране | Действие |
|---|---|---|---|
| Default | Нет заявки | «Наличные · банкомат в N мин» | → CASH |
| Active | Есть заявка | Кольцо + «Я у банкомата» | → REQ |
| Attention | Пункт кольца красный | Раскрытая проблема | → REQ / SH-REDIRECT |
| Empty geo | Нет локации | «Включить геолокацию» | → MAP списком |
| Loading | Старт Home | Скелетон строки | — |

### CASH

| Состояние | Триггер | На экране | Действие |
|---|---|---|---|
| Default | Нет заявки | «Снять без карты» + ближайший | HOWTO / NEW-AMT, MAP, DEP |
| Active | Есть заявка | Карточка REQ, создание скрыто | → REQ |
| Off | Выключено в Escudo | «Снятия выключены» + «Включить» | → ESC-CASH |
| First-time | Никогда не снимал | Строка «как это работает» | → HOWTO |
| Loading | Открытие | Скелетон карточки-ответа | — |

### NEW-AMT

| Состояние | Триггер | На экране | Действие |
|---|---|---|---|
| Default | Шаг 1 | Поле суммы, счета, цена | «Дальше» → NEW-ATM |
| Cheap | Кредит + хватает на Счёте | Шит SH-CHEAP | Счёт $0 / всё равно кредит |
| Validation | Не кратно / лимит / мало денег | Инлайн + альтернатива | Чип максимума / другой счёт |
| Loading | Смена счёта | Цена пульсирует | — |

### NEW-ATM / MAP / ATM-DET

| Состояние | Триггер | На экране | Действие |
|---|---|---|---|
| Answer | Есть рекомендация | «Избранный / по пути / ближайший, хватит» | «Дальше» / «Другой» → MAP |
| Loading | Поиск сети | Скелетон карточки | — |
| Empty geo | Отказ в локации | Список районов + «Включить» | MAP |
| Far | Нет банкомата рядом | «Ближайший за 48 мин» честно | Карта / чужая сеть (Won't сейчас) |
| Short cash | Не хватит купюр | Макс. доступная сумма или дальний | Уменьшить / другой |
| Closing | Не успеет до закрытия | Время в пути vs часы | 24ч альтернатива |
| Pin | Тап по пину | ATM-DET: фото, этаж, статус | «Снять здесь» |

### REQ

| Состояние | Триггер | На экране | Действие |
|---|---|---|---|
| Ready | 5/5 | «Всё готово», «Я у банкомата» | → ATM-MODE |
| Attention | Пункт сломался | Кольцо раскрыто + решение | SH-REDIRECT / NEW-AMT |
| Loading | Пульс телеметрии | Кольцо дышит | — |
| Expired | 24 ч | «Истекла», деньги на месте | Создать заново |
| Cancelled | Клиент отменил | Краткий итог | → CASH |

### ATM-MODE

| Состояние | Триггер | На экране | Действие |
|---|---|---|---|
| Check | Вход | Щит 0,5 с | Звонок → OV-CALL, запись → стоп |
| Hint | Всё ок | «На банкомате: Снятие по QR» | Сама → QR |
| Live QR | Подсказка прошла | Тёмный, узор 30 с, яркость max | Скан → SH-CONFIRM |
| No read | 10 с без скана | «Сними чехол, 10 см» | Ждать |
| Fallback | 30 с без скана | 8 цифр с экрана банкомата | Ввод в телефон |
| Screenshot | Снимок | Новый QR + «код уже не работает» | Продолжить |
| No network | Нет сети | Биометрия **до** QR, QR с ключа заявки | Скан офлайн |
| Dispense | Face ID ок | «Забери деньги», без закрыть | DONE / FAIL |
| Idle 3 мин | Нет действия | «Ты ещё у банкомата?» | Выйти / продолжить |

### SH-CONFIRM / DONE / FAIL

| Состояние | Триггер | На экране | Действие |
|---|---|---|---|
| Confirm | Скан ок | Сумма, комиссия, адрес банкомата | Face ID → выдача, «не я» → ESC-ALERT |
| Timeout 60 с | Нет подтверждения | Заявка снова активна | Повторить |
| Done | Выдача ок | Чек правды | Главная / проблема |
| Fail | Сбой / меньше / не забрал | Трекер возврата | MAP / чат |
| Loading | Ждём банкомат | «Подтверждаем с банкоматом…» | Нет ухода |

## 4. Развилки

**Первый раз?**
- Да → HOWTO → NEW-AMT
- Нет → NEW-AMT (чип прошлой суммы, «мой банкомат»)

**Есть активная заявка?**
- Да → любой вход → REQ, создание скрыто
- Нет → CASH → создание

**Счёт: кредит при живых деньгах на Счёте?**
- Да → SH-CHEAP
- Нет → NEW-ATM

**Банкомат в заявке открыт / работает / хватит купюр / баланс / срок?**
- Все зелёные → «Я у банкомата»
- Нет → SH-REDIRECT или правка суммы. Тупика «напишите в поддержку» нет

**Звонок, пока виден QR?**
- Да → OV-CALL (продолжить / отменить / чат)
- Нет → живой QR

**Банкомат прочитал QR?**
- Да → SH-CONFIRM
- Нет 10 с → подсказка; 30 с → 8 цифр; N попыток → блок 15 мин

**Это я?**
- Face ID → выдача
- «Это не я» → отмена на банкомате + ESC-ALERT
- 60 с молчания → заявка жива, можно повторить

**Купюры выданы?**
- Да, ровно → DONE
- Меньше / ноль / не забрал → FAIL + автовозврат

## 6. Пока не рисовать

- Внесение наличных (DEP*) — другая работа, тот же хаб, отдельный флоу
- Семейный счёт и доверенный контакт (Could)
- Аварийный PIN при принуждении — юридический вопрос
- Вход из «Платежи», сканер QR на Главной, «Поделиться / Сохранить» QR снятия
- Код из пуша в банкомат, QR на 5 минут «в кармане», привязка заявки к одному банкомату
- Пополнение по карте / телефону / договору на банкомате
- Лимиты Т-банка 1 000–600 000 ₽
