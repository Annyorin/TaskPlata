Геолокация, точки на карте, маршрут, QR, пуш и выдача моделируются в браузере. Комиссия для дебетового и накопительного счёта $0, для кредитного $10. Лимит ввода $9,900, срок заявки 24 часа. Активная заявка определяет, какое состояние Home открывается.

Страница кейса — `public/case/index.html`. После сборки открывается по `/case/index.html`; кнопка «Открыть прототип» ведёт к приложению в корне той же сборки.
