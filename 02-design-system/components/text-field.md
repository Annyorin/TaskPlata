# Text field

## Назначение
Однострочный ввод: телефон, поиск адреса. Сумма — отдельная семья.

## Анатомия
Белая капсула с радиусом 12. Текст `Foundation/Body LG`. Отступы 16. Высота 52. Очистка — серый круг 16 (`gray/300` `#C5C6CB`) с белым крестом, как на поле адреса. Курсор — чёрная черта 2×20 сразу после текста.

## Варианты
| Вариант | Значения | Когда |
|---------|----------|-------|
| State | Empty, Focus, Filled, Clear | Пустое, курсор, значение, значение с очисткой |
| Value | текст | У Empty значения нет |

Кадр пачки `2327:1182`.

## Состояния
Пустое, фокус и заполненное сняты с кадров. Цветной рамки у фокуса нет. Disabled и error на кадрах не было: подпись ошибки не показана.

## Токены
| Свойство | Токен |
|----------|-------|
| Заливка | bg/surface |
| Текст | text/primary, Body LG |
| Радиус | radius/12 |
| Отступ | space/16 |

## Правила применения
На ширину блока. Крестик только когда в поле уже есть текст.

## Чем не является
Поле суммы крупнее и несёт подпись справа («без комиссии»).
