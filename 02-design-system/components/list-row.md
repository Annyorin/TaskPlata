# List row

## Назначение
Строка в шите и на экране карты: переход дальше или человек с реквизитом.

## Анатомия
Слева пусто, иконка 24 или аватар 40. По центру заголовок `Foundation/Body LG`, при двух строках подпись `Foundation/Body MD`. Справа шеврон 24, обводка 2. Отступы 12 по вертикали и между частями, 16 по бокам. Высота одной строки 48. Длинный текст заканчивается многоточием.

## Варианты
| Вариант | Значения | Когда |
|---------|----------|-------|
| Leading | None, Icon, Avatar | PIN без знака, способ перевода, человек |
| Lines | One, Two | Заголовок или заголовок с реквизитом |
| State | Default, Pressed | Нажатие — заливка `bg/pressed` |
| Title, Subtitle, Initials | текст | Subtitle только у двух строк, Initials у аватара |

12 вариантов. Кадр пачки `2326:1224`.

## Состояния
Default снят с кадров. Pressed на кадрах не было. Disabled, loading и error у строки нет.

## Токены
| Свойство | Токен |
|----------|-------|
| Фон | bg/surface |
| Нажатие | bg/pressed |
| Заголовок | text/primary, Body LG |
| Подпись | text/secondary, Body MD |
| Аватар | gray/200 |

## Правила применения
На ширину блока. Разделителей между строками нет, снаружи шаг 4. Иконка способа перевода пока одна (банк); разные знаки — подмена, не новые варианты.

## Чем не является
Переключатель в строке безопасности и ручка перетаскивания в избранном в этот набор не входят: у переключателя нет измеренного синего.
