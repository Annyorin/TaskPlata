# Labeled field

## Назначение
Поле на шите «Confirm address»: индекс, город, улица, дом.

## Анатомия
Белая капсула, радиус `radius/16`, отступ 16. Заполненное: подпись `Body SM` цветом `text/secondary` и значение `Heading SM`. Пустое: одна серая строка-плейсхолдер `Body LG`.

## Варианты
| Вариант | Значения | Когда |
|---------|----------|-------|
| Kind | Filled, Empty | Есть значение или только подсказка |
| Caption, Value | текст | Подпись и значение заполненного |
| Placeholder | текст | Пустое поле |

Кадр `2342:1744`.

## Чем не является
Не поле поиска адреса: у того одна строка и крестик очистки.
