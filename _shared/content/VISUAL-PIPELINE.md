# Визуальный пайплайн — теория и инструменты

Корневые знания для генерации изображений в продуктовом дизайне. Работают
независимо от того, какая модель сейчас на пике.

## 1. Архитектуры моделей

| Тип | Как работает | Сильные стороны | Типичные инструменты |
|-----|--------------|-----------------|----------------------|
| **Диффузионные** | шум → изображение за N шагов denoise | фотореализм, текстуры, деталь | SD, Midjourney, Flux |
| **Гибридные авторегрессивные** | токены изображения + диффузия / refinement | текст в кадре, композиция, скорость | Flux 2, некоторые GPT Image |

**Практика:** для **иллюстраций и стиля** — диффузия + sref; для **текста в кадре**
и **редактирования** — гибриды и GPT Image; для **итераций в реальном времени** — Krea canvas.

## 2. Режимы генерации

| Режим | Когда | Риск |
|-------|-------|------|
| **Text-to-image** | с нуля, есть только бриф | дрейф стиля между кадрами |
| **Image-to-image** | есть коллаж, скетч, референс | потеря композиции при высоком strength |
| **Reference-based** | нужен единый стиль (персонаж, бренд) | переобучение на референс |
| **Inpainting** | заменить область | шов на границе маски |
| **Outpainting** | расширить холст | повторяющиеся паттерны по краям |

Выбор режима фиксируется в `visual/prompts/<asset>.json` → поле `mode`.

## 3. Структурированные промпты и JSON

Воспроизводимая серия = один JSON-шаблон + вариации `subject` / `scene`.

```json
{
  "asset_key": "onboarding.hero",
  "mode": "text-to-image",
  "tool": "midjourney",
  "style": {
    "sref": "https://…",
    "sref_weight": 100,
    "palette": ["#1a1a2e", "#e94560"],
    "negative": ["text, watermark, blurry hands"]
  },
  "composition": {
    "aspect": "16:9",
    "focal_point": "center-left",
    "camera": "medium shot, eye level"
  },
  "subject": "…",
  "scene": "…",
  "lighting": "soft diffused, golden hour",
  "seed": null,
  "notes": "серия 1/4 — тот же sref"
}
```

Шаблон: [`../templates/visual-prompt.json.md`](../templates/visual-prompt.json.md).

## 4. Матрица «задача → инструмент»

| Задача | Инструмент | Скилл / ветка |
|--------|------------|---------------|
| Бриф + JSON (режим, tool) | — | `visual-prep` |
| Иллюстрации в едином стиле, серии | Midjourney + sref | `visual-generate` → midjourney |
| Быстрые итерации, Flux 2, апскейл | Krea | `visual-generate` → krea |
| Брендовые иконки/паттерны сеткой 4K | Nano Banana Pro | `visual-generate` → nano-banana |
| Редактирование, style transfer, текст | GPT Image | `visual-generate` → gpt-image |
| Коллаж / wireframe → финал | i2i (Krea / MJ / GPT) | `visual-generate` → collage-i2i |
| Композиция слоёв, итерации нодами | Figma Weave | `figma-weave` |

## 5. Midjourney — sref для серий

- Собери **style reference** из 3–5 лучших кадров бренда → `--sref <url>`.
- Веди `visual/styles/sref-library.md`: URL, вес, для каких ассетов.
- Серия: один sref + меняется только `subject` / `scene` в JSON.
- `--sw` (style weight) 50–150: выше — жёстче стиль, ниже — свободнее композиция.

## 6. Krea — Flux 2 Pro и canvas

| Возможность | Зачем в продукте |
|-------------|------------------|
| **Flux 2 Pro** | качество финальных кадров, деталь |
| **Real-time canvas** | набросок → мгновенная генерация, поиск композиции |
| **Style Explorer** | быстрый перебор стиля без нового промпта |
| **Апскейлеры** | финальный размер для retina / hero |

Workflow: canvas (композиция) → Flux 2 Pro (финал) → upscale → в `visual/assets/`.

## 7. Nano Banana Pro — «Сетка 4K»

Метод для **наборов брендовых ассетов** (иконки, текстуры, паттерны):

1. Один промпт на **сетку** (например 4×4) в одном стиле.
2. Генерация в 4K → нарезка на отдельные файлы.
3. Именование: `<asset_key>__<row>-<col>.png`.
4. Метаданные сетки — в `visual/briefs/<set>.md`.

Единый стиль важнее идеального отдельного кадра — сетка выравнивает палитру и линию.

## 8. GPT Image — редактирование

- **Многошаговое редактирование:** каждый шаг — отдельный файл + запись в
  `visual/assets/<asset>-steps.md` (что меняли, зачем).
- **Style transfer:** референс стиля + целевая композиция; не смешивать с sref MJ.
- Сильная сторона — **текст в кадре** и **точечные правки** без перегенерации всего.

## 9. Low-fi коллаж → финал (image-to-image)

1. Собери коллаж: скрин + стрелки + подписи ролей (Figma / бумага / Excalidraw).
2. Экспорт PNG → `visual/assets/<asset>-collage.png`.
3. i2i с **низким–средним strength** (0.35–0.55): сохранить композицию, сменить стиль.
4. Финал — через Krea или MJ с референсом коллажа.

## 10. Figma Weave — нодовые пайплайны

Weave — сборка **визуальных** цепочек внутри Figma (не UI-компоненты DS).

| Шаблон пайплайна | Назначение |
|------------------|------------|
| **Welcome** | старт: промпт + референсы + aspect |
| **Iterations** | ветвление вариантов, A/B визуала |
| **Editing** | inpaint, upscale, color fix |
| **Compositor** | слои: фон + персонаж + UI-оверлей для маркетинга |

Артефакт: `visual/weave/<asset>-pipeline.md` — схема нод + ссылки на входы/выходы.
Протокол MCP: `infra/figma-mcp` + weave-инструменты Figma MCP.

## 11. Качество визуала

- Каждый ассет имеет **ключ** (`hero.onboarding`) как у текста.
- Промпт JSON — источник правды; PNG — производное.
- «Красиво» без брифа и инсайта — не в пакет.
- Продуктовые экраны (UI) — `build/design-loop` и среда 4, не hero-иллюстрации MJ.

Человеческий обзор: [`../reference/visual-generation-methods.md`](../reference/visual-generation-methods.md).
