# Deep Research — фаза 1a (опционально)

## Среда

`01-research/`. Результаты — в `sources/deep-research/`:
- `sources/deep-research/<slug>.md` — по одному отчёту на тему;
- ссылки и цитаты — с `reliability` и датой доступа.

Предусловие: `briefs/00-research-scope.md` (фаза 0).  
Обычно идёт **после** `recursive-briefing` или **параллельно** с ним, если вводных мало.

## Goal

Быстро закрыть пробелы в знаниях о рынке, аудитории, технологиях и контексте —
до точечного конкурентного анализа. Не заменяет фазы 2–3, а питает их сырьём.

## Инструменты

| Инструмент | Когда | Что даёт |
|------------|-------|----------|
| **Gemini Deep Research** | широкий обзор темы, тренды, сравнения | многостраничный отчёт с источниками |
| **Antigravity (агент)** | итеративный поиск, сводка, структурирование | агентный цикл «запрос → поиск → синтез» |

Оба — **внешние** инструменты. Агент в Cursor не вызывает их напрямую: пользователь
запускает research в Antigravity / Gemini DR, затем передаёт результат в `sources/`.

## Process

1. Из `briefs/00-research-scope.md` и `briefs/01-product-brief.md` (если есть) выдели
   **3–5 исследовательских вопросов**, которые нельзя закрыть из имеющихся данных.
2. Сформулируй промпт для Deep Research (см. ниже). Один промпт — одна тема.
3. Пользователь запускает в **Gemini Deep Research** или через **агента Antigravity**.
4. Экспорт отчёта → `sources/deep-research/<slug>.md` по формату INPUT-FORMAT.
5. Выдели **наблюдаемые факты** (цитаты, цифры, ссылки) — без интерпретации.
6. Открытые вопросы, которые отчёт не закрыл — в `briefs/01-product-brief.md`
   раздел «Открытые вопросы» или в `NOTES.md`.

### Промпт-шаблон для Gemini DR / Antigravity

```markdown
Контекст: [продукт / сегмент / география из scope]
Исследовательский вопрос: [один чёткий вопрос]
Границы: [что не включать]
Нужно в ответе:
- факты с источниками (URL, год)
- размер рынка / тренды (если есть данные)
- ключевые игроки (названия, не оценки UX)
- регуляторика / ограничения (если релевантно)
- пробелы: чего в открытых источниках нет
Формат: структурированный отчёт, каждый тезис — со ссылкой.
```

## Gate

Переход к `competitive-scan` или `insight-synthesis` — если:
- [ ] ≥1 отчёт сохранён в `sources/deep-research/`;
- [ ] у каждого факта есть источник или пометка `reliability: low`;
- [ ] в `NOTES.md` зафиксировано, какие вопросы закрыты / остались.

## Rules

- Deep Research **не** подменяет интервью с пользователями и не даёт UX-выводов без скринов.
- Цифры без источника — гипотеза, не факт.
- Не копировать отчёт целиком в `insights/` — только сырьё в `sources/`.
- Если пользователь не может запустить Antigravity / Gemini DR — пропусти фазу,
  зафиксируй в PRD раздел «Что не исследовали».
