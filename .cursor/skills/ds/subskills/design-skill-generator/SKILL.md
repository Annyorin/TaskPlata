# Design skill generator

Источник: [weareoxd/design-skill-generator](https://github.com/weareoxd/design-skill-generator), MIT. В репозитории это веб-приложение. Здесь лежит его промпт, без запуска Next и без ключа Anthropic.

Активная версия промпта — `prompts/spec-v1.ts`. Короткая версия — `prompts/prose-v1.ts`.

## Когда

Есть скриншоты приложения или ссылка на кадр Figma, и нужен файл, по которому агент дальше держит цвет, текст, отступы и компоненты. Это не запись в Figma и не вёрстка экрана.

## Как

1. Возьми все переданные экраны сразу, не по одному.
2. Иди по секциям `spec-v1.ts`: цвет, типографика, отступы, компоненты, иконки, формы, данные, состояния, движение, адаптив, запреты.
3. Пиши конкретные значения. Цвет называй ролью и hex, не словом «синий».
4. Сохрани два файла рядом с задачей:
   - `SKILL.md` — правила и секции
   - `tokens.css` — `:root` с переменными, на которые ссылается `SKILL.md`
5. Не выдумывай значение, которого не видно. Если состояние или брейкпоинт не показаны, так и напиши.

Приложение из исходного репозитория не устанавливай: тот же результат собирается по промпту в этом каталоге.
