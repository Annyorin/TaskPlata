# Quality — роутер группы

Среды: `04-prototype/` и `05-code/`. Подскиллы — `subskills/<имя>/SKILL.md`.

| Задача | Подскилл |
|--------|----------|
| соответствие DS, a11y, состояния | `design-review` |
| ИИ-паттерны в UI | `design-anti-slop` |
| доводка до визуального эталона | `design-decompose` |
| анимации, easing | `emil-design-eng` |
| юзер-тесты → findings → правки/контракты | `user-test-loop` |

## Вопросы

| Вопрос | Подскилл |
|--------|----------|
| соответствует ли **нашей системе** | `design-review` |
| опознаётся ли как **нейронка** | `design-anti-slop` |
| дотягивает ли до **эталона** | `design-decompose` |
| ощущается ли **живым** | `emil-design-eng` |
| что сказали **тестеры** и что чинить | `user-test-loop` |

## Режимы

**Точечный** — один подскилл.  
**Полный прогон** — параллельные read-only `Task` по аспектам; правки после апрува.

`user-test-loop` обычно **после** `build/ship`, не вместо визуального ревью.

## Границы

Изменение DS — контракт в среду 2.  
`design-review` читает зеркало Prototype, не внутренности среды 2.

## Дедуп-вахта

- Каталог анти-паттернов: `design-anti-slop/references/catalog.md`.
- Оживление прототипа — `build/app-live`, не emil в одиночку.
- GitHub/деплой — `build/ship`.
