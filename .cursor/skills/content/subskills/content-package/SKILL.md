# Content Package — фаза 6

## Среда

`03-content/`. Результат: `outputs/content-package.md`.

Предусловие: минимум ToV + один из треков (copy или visual) заполнен.

## Process

1. Собери все ключи из `copy/` и `visual/briefs/`.
2. Таблица **Тексты**: ключ | текст | роль | инсайт.
3. Таблица **Изображения**: ключ | файл | бриф | промпт JSON | инструмент.
4. **ToV выжимка** — 3–5 буллетов для среды 4.
5. **Визуальные стили**: ссылка на `visual/styles/sref-library.md` если есть.
6. Frontmatter: `status: ready` когда gate пройден.

## Gate

- [ ] каждый ключ уникален;
- [ ] тексты с трассировкой;
- [ ] ассеты: файл существует + есть brief + prompt JSON;
- [ ] нет «висящих» брифов без ассета (или помечены `pending`).

## Rules

- Пакет — **единственный** публичный выход; среда 4 не читает `copy/` напрямую.
- Визуал без JSON-промпта — не `ready`.
- Инкремент: обновляй пакет после каждой завершённой фазы, не копи в конце.

## После пакета

Среда 4 (Prototype) подставляет тексты и ассеты по ключам при сборке экранов.
