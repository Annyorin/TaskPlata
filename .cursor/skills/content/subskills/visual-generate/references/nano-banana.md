# Nano Banana Pro — «Сетка 4K»

Предусловие: JSON с блоком `grid` (и обычно `tool` nano-banana).

## Результаты

- `visual/assets/<set_key>__<row>-<col>.png`;
- таблица ячеек в `visual/briefs/<set_key>.md`.

## Process

1. Сетка (типично 4×4); содержимое каждой ячейки.
2. Один промпт на всю сетку: общий стиль + перечень ячеек L→R, T→B.
3. Генерация в **4K**.
4. Нарезка; имена `__row-col`.
5. В брифе: ячейка → asset_key → роль в продукте.

## Gate

- [ ] все ячейки нарезаны;
- [ ] палитра и линия согласованы;
- [ ] ключи готовы к content-package.

## Rules

- Единство стиля важнее идеальной одной иконки.
- Плохая ячейка → перегенерация сетки, не точечный GPT.
- Не для уникальных hero — там Midjourney / Krea.
