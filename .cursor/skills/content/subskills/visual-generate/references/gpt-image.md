# GPT Image — редактирование и style transfer

Предусловие: JSON с `"tool": "gpt-image"`.

## Результаты

- `visual/assets/<asset_key>.png`;
- `visual/assets/<asset_key>-steps.md` при ≥2 шагах.

## Process

### Многошаговое редактирование

1. Шаг 0: исходник.
2. Один шаг = одна операция.
3. Лог:

| Step | Операция | Промпт | Файл |
|------|----------|--------|------|
| 1 | … | … | -s1.png |

4. Финал → `<asset_key>.png`.

### Style transfer

1. Style ref из `style.style_ref_image` (не MJ sref URL напрямую).
2. Content ref — композиция / коллаж.
3. Явно: что переносим (стиль) vs что сохраняем (композиция).

## Gate

- [ ] лог при ≥2 итерациях;
- [ ] текст в кадре читаем (если нужен);
- [ ] нет артефактов на границах.

## Rules

- Хирургия и текст, не массовые серии.
- Не смешивать с MJ sref без конвертации референса.
