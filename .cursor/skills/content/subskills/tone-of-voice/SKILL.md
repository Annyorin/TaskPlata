# Tone of Voice — фаза 0

## Среда

`03-content/`. Результат: `strategy/tone-of-voice.md` по шаблону
[`tone-of-voice.md`](../../../../../_shared/templates/tone-of-voice.md).

Вход: `01-research/outputs/research-digest.md` только.

## Process

1. Из дайджеста вытащи сегменты, боли, язык аудитории, main job.
2. Сформулируй 3–5 прилагательных голоса — с обоснованием из инсайтов.
3. Do / Don't — конкретные формулировки, не «будь дружелюбным».
4. Таблица лексики: что говорим / чего избегаем (жаргон PM, канцелярит).
5. ≥2 пары «плохо / хорошо» с ссылкой на инсайт.

## Gate

- [ ] каждый принцип связан с дайджестом;
- [ ] есть do и don't;
- [ ] примеры не противоречат друг другу.

## Rules

- ToV влияет и на **визуал** (эмоция кадра) — ссылайся из `visual/briefs/`.
- Нет данных в дайджесте → контракт к среде 1.
