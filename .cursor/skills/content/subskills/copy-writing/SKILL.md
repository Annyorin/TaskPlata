# Copy Writing — фаза 1

## Среда

`03-content/`. Результат: `copy/<screen-or-entity>.md` — один файл на экран или сущность.

Предусловие: `strategy/tone-of-voice.md`.

## Формат блока

```markdown
### `onboarding.title`
**Роль:** заголовок hero онбординга
**Текст:** …
**Инсайт:** → research-digest §…
```

## Process

1. Список экранов/сущностей — из PRD/digest или запроса пользователя.
2. Для каждого блока: ключ `screen.element` (stable для среды 4).
3. Пиши по ToV; длина — под мобильный первый экран.
4. CTA — глагол + исход (не «Далее» без контекста).
5. Ошибки — что случилось + что делать.

## Gate

- [ ] у каждого значимого текста есть ключ и инсайт;
- [ ] нет текстов вне ToV без пометки «исключение»;
- [ ] микрокопи согласованы (одна сущность — одно имя).

## Rules

- Не описывай компоненты DS — только роль («заголовок», «подпись поля»).
- Текст без инсайта — кандидат на удаление или контракт к Research.
