# Чек-лист проверки страницы

Снять экран на 1440 и 390:

```
npx playwright screenshot --viewport-size=1440,900 --full-page http://localhost:5173 screenshots/page-1440.png
npx playwright screenshot --viewport-size=390,844 --full-page http://localhost:5173 screenshots/page-390.png
```

Пройти по пунктам, исправить одним заходом, переснять. Максимум два круга.

## Система
- [ ] Каждая секция собрана из компонентов Storybook. Ни одного стиля «только здесь».
- [ ] В коде страницы нет цветов и размеров цифрами, только токены. Допустимы только брейкпоинт в media query, 1px и смещение фокусной рамки.
- [ ] Новые компоненты, если появились, есть в витрине с историями.

## Верстка
- [ ] На 390 нет горизонтальной прокрутки, ничего не наезжает, кнопки помещаются.
- [ ] Заголовки не оставляют одно слово на последней строке (в стиле заголовков `text-wrap: pretty`, длинные заголовки переносить вручную).
- [ ] Над заголовками воздуха больше, чем под ними.
- [ ] Контраст текста читаемый на всех фонах, включая вторичный текст.
- [ ] Шрифт из DESIGN.md реально загружен, не подменён системным.

## Нейросетевой дефолт (если есть хоть один пункт, страница не готова)
- [ ] Индиго-фиолетовые градиенты и градиентный текст.
- [ ] Всё в одинаковых карточках по центру, ряд одинаковых карточек с иконкой, заголовком и текстом.
- [ ] Ярлык-подпись над каждым заголовком, номера секций 01/02/03.
- [ ] Эмодзи вместо иконок.
- [ ] Цветная полоска слева на карточках.
- [ ] Стекло и размытие как украшение.
- [ ] Анимации «влетания» на каждой секции.

## Контент
- [ ] Реальные тексты пользователя, плейсхолдеры с видимой пометкой «заменить».
- [ ] Ни одной выдуманной цифры, цены, отзыва, имени.
- [ ] Одна формулировка главного действия на всей странице.

## Сдача
- [ ] Адрес страницы, адрес Storybook, список замен.
