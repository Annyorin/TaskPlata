# Разложить скриншоты по экранам

В папке screenshots лежат скриншоты банковского приложения. Разложи их по папкам: одна папка на один экран приложения. Каждый файл переименуй так, чтобы было понятно, что на нём: экран и состояние, например «перевод, ввод суммы». Если два скриншота показывают один экран в разных состояниях, положи их в одну папку. В конце покажи список папок и файлов и отметь скриншоты, которые не получилось отнести к экрану.

## Безопасная среда для агента

- У агента своя папка, важные рабочие файлы лежат вне её
- Перед задачей есть свежая копия папки, из которой можно восстановить файлы
- У агента нет доступа к рабочим базам, аккаунтам и чужим проектам
- Результат первой задачи ты проверил сам, прежде чем дать следующую
